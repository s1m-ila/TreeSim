# TreeSim

**TreeSim** — симуляция эволюции и роста деревьев на дискретной 2D-карте с расчётом освещённости и генетическим алгоритмом. Проект построен на базе ядра [SMPB](https://github.com/s1m-ila/SMPB), 2D-рендерера [SMGC](https://github.com/s1m-ila/SMGC) и графического интерфейса [sm-gui](https://github.com/s1m-ila/sm-gui).

## Основные механики

- **Рост и геном**: каждое дерево развивается по матрице генов (30 генов по 4 направлениям роста и условию образования семян).
- **Энергия и солнце**: свет падает сверху вниз. Кроны поглощают солнечные лучи и затеняют пространство снизу. Для поддержания жизнедеятельности клетки расходуют энергию.
- **Размножение и мутации**: созревшие семена падают вниз под действием гравитации. При прорастании семени возможны мутации генома, порождающие новые формы кроны.
- **Естественный отбор**: выживают и дают потомство структуры, наиболее эффективно собирающие свет и экономно расходующие энергию.

## Интерфейс и управление

### Симуляция
- `Space` — пауза / возобновление симуляции.
- `E` / `Q` — увеличение / уменьшение скорости (с `Shift` шаг 10, с `Ctrl` шаг 100).
- `M` — переключение режима визуализации (цвета генома / уровень освещения).
- `R` — сброс карты к начальному состоянию (когда редактор не активен).
- `O` — переключение контуров клеток.
- `ЛКМ` по карте — инструмент-пипетка (выбрать дерево или семя для просмотра на мини-карте и редактирования).
- `ПКМ` по карте — посадить семя с текущим выбранным/отредактированным геномом в указанную клетку.

### Редактор генома и мини-карта
- **Мини-карта (слева внизу)** — визуализирует изолированный рост дерева до последнего тика жизненного цикла в реальном времени при любых изменениях генома.
- **Редактор (справа внизу)** — отображает 30 строк генов:
  - Клик по кнопке любого гена (`0`–`29`) переводит его в режим ввода текста.
  - Ввод чисел с клавиатуры, разделитель `;`, навигация стрелками `Left` / `Right`, клавиши `Home` / `End`, удаление `Backspace` / `Delete`.
  - `R` — мгновенная очистка редактируемого гена в `0; 0; 0; 0; 0` с немедленным перерасчётом дерева на мини-карте.
  - `Enter` — подтвердить изменения гена.
  - `Escape` — отменить редактирование.

## Сохранение и загрузка (`saves/`)

Все данные сохраняются в каталог `saves/` (создаётся автоматически):

### Геномы (`saves/genomes/`)
- Каждому геному по умолчанию присваивается случайное органическое имя (например, `Cedar_042`, `Flora_815`).
- Кнопка `Gen: <имя>` позволяет ввести своё кастомное имя (кликом по ней включается редактирование с клавиатуры).
- Название записывается как в имя файла (`<имя>.gen`), так и внутри первой строкой (`Name: <имя>`).
- `Save Gen` — сохранить текущий геном в файл.
- `Load Gen` — открыть диалоговое окно со списком сохранённых геномов (отсортированных по дате изменения) для быстрой загрузки в редактор.

### Карты симуляции (`saves/maps/`)
- Кнопка `Map: <имя>` позволяет задать кастомное имя сохраняемой карты. Если имя не задано, по умолчанию используется дата и время (`YYYY-MM-DD_HH-MM-SS.map`).
- `Save Map` — бинарное сохранение полного состояния симуляции (размеры, поколение, клетки, геномы, деревья, падающие семена).
- `Load Map` — открыть диалоговое окно со списком сохранённых карт для мгновенной загрузки.

*В диалоговых окнах выбора файлов кнопку `[Cancel]` или клавишу `Escape` можно использовать для закрытия без загрузки.*

## Сборка и запуск

### Требования
- C++23 компилятор (GCC или Clang)
- CMake 3.16+
- Библиотеки: OpenGL, GLFW, GLM
- Зависимости `SMPB`, `SMGC` и `sm-gui` (расположенные рядом в родительском каталоге)

### Сборка через Nix

```bash
nix-shell
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### Запуск

```bash
./build/TreeSim
```
